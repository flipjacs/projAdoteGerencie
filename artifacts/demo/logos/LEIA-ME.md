# Logos de referência da demonstração

Os nomes e registros “Amigos da Floresta” (ONG ID 1) e “Patinhas do Rio Negro” (ONG ID 2) são dados fictícios desta demonstração. As organizações cujos logos aparecem abaixo são reais, mas não têm vínculo com os registros demonstrativos. Os logos são usados apenas como referências visuais, sem alegação de patrocínio, parceria ou endosso.

Os logos não devem ser tratados como identidade visual oficial das ONGs fictícias. O aplicativo Android exibe junto de cada um o aviso: “Logo de referência; ONG demonstrativa sem vínculo com a organização.”
